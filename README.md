Sunday 22 November 2026 — The World in One Day. A dense one-page broadsheet front page: 35 stories across 7 regions, 13 original drawn illustration panels (3 leads + 10 mediums), a KPI strip, a Sunday-only UTC timeline, a dotted world map with numbered pins and place labels, a numbered "also today" list, certainty tags with a legend, and a DATE CHECK box naming every big story left out as other days' news. Every story happened, or was first reported, on Sunday 22 November 2026 only — the lead is the real overnight count, 186 drones (161 downed), not the 400-drone barrage of 19–20 November.

## Run it

```sh
python3 main.py
```

Copies the pre-rendered `entry.png` (1024x1024) to the output directory. Set `MAKEFUN_OUTPUT_DIR` to choose the output directory, or pass a path: `python3 main.py /path/to/entry.png`. Pure standard library — no third-party packages needed.
